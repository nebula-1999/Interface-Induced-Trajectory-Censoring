\section{Limitations}
\label{sec:limitations}

We list these in the order a sceptical reader should apply them, and we mark which are
budget limitations (removable with more compute) and which are design limitations of the
present study.

\subsection*{Scope of the evidence}

\begin{enumerate}
\tightlist
\item
  \textbf{One task family, one tool.} All arms use decontaminated KodCode programming items
  with a single tool, \texttt{run\_tests}, taking a single \texttt{code} argument. Multi-tool
  schemas, tool selection among alternatives, and non-code domains are untested. A
  single-tool schema is the \emph{easiest} case for a parser, which if anything makes the
  measured censoring a lower bound --- but that is an argument, not a measurement.
\item
  \textbf{Item sampling.} 100 items per arm, taken as \texttt{clean[:100]} --- \textbf{not a
  random sample}. Pairing across arms is exact (verified: all 50 full-length arms share one
  item set), so within-study comparisons are sound; generalisation to the corpus is not
  established. A random-sample replication at $n=300$ is scripted but was not run
  (\S\ref{sec:future}).
\item
  \textbf{The scale result is within one family.} The $0\to4\to21\to36\to80$ ladder is
  Qwen2.5-Coder alone, against one mismatched interface, on one task. We claim a
  within-family monotone relation between checkpoint size and absolute undercount. We do
  \emph{not} claim that censoring is generally scale-increasing, and we do not equate
  parameter count with capability. A second family's scale ladder is the cheapest test that
  would promote or refute this.
\item
  \textbf{The taxonomy is four instances, not an enumeration.} The evidence behind the four
  layers is deliberately asymmetric: Qwen has a scale ladder, an offline replay matrix and a
  repair; Llama has a single-variable intervention; \textbf{Mistral has no admissible
  100-item FC comparison at all} (every configuration produces request errors); DeepSeek is
  a template check with little quantification. Read it as four concrete failure modes
  motivating a layered decomposition, not as a complete partition of the failure space.
\item
  \textbf{Single-sample main table.} \S5.4 is one sample at \texttt{temperature}=0. Variance
  is estimated only on Llama-3.1-8B, and there only 2 of 3 FC arms are admissible, which is
  too few for a standard deviation.
\item
  \textbf{Multiple comparisons.} Roughly a dozen McNemar tests, \textbf{uncorrected}. The
  main effects (order $10^{-3}$) survive Bonferroni at this family size; the marginal
  results ($p$=0.093, 0.118, 0.125) do not, and we do not rest any claim on them.
\item
  \textbf{Model scale stops at 32B}, on a single A800; no frontier models.
\end{enumerate}

\subsection*{Threats to the causal reading}

\begin{enumerate}
\setcounter{enumi}{7}
\tightlist
\item
  \textbf{There is no clean repaired-FC training control.} The training evidence compares FC
  against ReAct, which changes \textbf{protocol and interface together}. ReAct is a
  positive-control interaction channel, not a parser-repair control. The experiment that
  would isolate the interface --- broken-FC RL versus repaired-FC RL, everything else held
  fixed --- is not constructible in verl 0.9.0, whose vLLM rollout path exposes no guided
  decoding (\S5.6). Consequently we claim that \textbf{interface censoring can be observed
  directly inside rollout collection and eliminates tool-mediated samples}; we do
  \textbf{not} claim to have causally proven that it prevents RL from learning multi-turn
  repair.
\item
  \textbf{Conditioning on a successful parse is post-treatment conditioning.} Whether an item
  parses is itself determined by the interface under test, so the both-parsed subset is not
  a random subsample and its contrast is not a clean causal estimate. We present it as a
  diagnostic decomposition. On Qwen the residual is $+8.4$\,pp with 95\% CI $[-0.5,+17.4]$
  ($p$=0.118): \textbf{we do not detect a residual difference, which is not the same as
  establishing there is none} --- the interval admits an effect larger than the one we do
  detect on Llama.
\item
  \textbf{Observed zero is not zero probability.} Our rollout instrumentation records zero
  parser-accepted tool executions across every step of the FC arm. That is a statement about
  the sampled experience distribution, not about the support of the policy: entropy and
  off-branch parameter updates could in principle carry the model into parser-compatible
  output. We therefore say the tool-using branch \textbf{receives no direct on-policy
  gradient signal under the observed rollout distribution} and is \textbf{effectively
  inaccessible in this cold-start regime}, rather than mathematically unreachable.
\item
  \textbf{Zero executions is not zero attempts.} The FC training arm did not save raw rollout
  text, so we cannot separate ``never attempted'' from ``attempted and discarded''. The
  probe replication at the same scale and prompt (\S5.6) finds no output naming
  \texttt{run\_tests}, which makes ``nothing well-formed to censor'' the most likely reading
  \emph{at 1.5B} --- but it is a replication, not the training run itself.
\item
  \textbf{Opening the channel is tested only through ReAct.} The 75-step arm executing
  23{,}676 calls (\S\ref{sec:sufficiency}) shows that a working channel does not by itself
  move multi-turn rescues. Because it is not a parser-repair control, it cannot separate ``a
  working channel is insufficient'' from ``ReAct in particular is insufficient'', and it is
  75 steps on one seed at 1.5B against 150-step historical baselines.
\item
  \textbf{Human validation covers one criterion on one sample.} Two independent blind
  annotators on 98 stratified items give inter-annotator $\kappa$ = 0.967 on the 62 items
  where both read identical bytes, and classifier-vs-gold-standard $\kappa$ = 0.871 after
  third-party adjudication of all fifteen non-unanimous items (\S3.2). Two residual limits
  remain. (i) The sample is stratified by classifier verdict, so it estimates per-stratum
  precision and recall, not a population rate. (ii) The stored raw output is capped at
  4000 characters, so a call
  emitted past that point is invisible to the classifier and to both annotators alike ---
  emitted-call counts are a lower bound. We also note that the \emph{first} annotation
  round's apparent unreliability ($\kappa$=0.713) was an artefact of a 2400-character
  truncation in the annotation pack, not of the raters; that pack is superseded.
\end{enumerate}

\subsection*{Environment dependence and provenance}

\begin{enumerate}
\setcounter{enumi}{13}
\tightlist
\item
  \textbf{Serving-stack version dependence.} Every measurement is against vLLM 0.27.1 and
  verl 0.9.0. Parser behaviour, template defaults and the semantics of \texttt{strict: true}
  are properties of those versions; a stack upgrade may change any number here. We pin
  versions, parser and template hashes, and model revisions for exactly this reason. We have
  not replicated on a second serving stack (e.g.\ SGLang), so we cannot say which findings
  are vLLM-specific.
\item
  \textbf{Repository-revision dependence.} Chat templates ship inside
  \texttt{tokenizer\_config.json} in the model repository and can be changed by the
  publisher without a model change. The Qwen2.5-Coder false positive in \S5.1 is precisely
  an artefact of an inherited template; a later revision could remove or alter it.
\item
  \textbf{Instrumentation errata, disclosed rather than absorbed.} Seven ReAct arms recorded
  \texttt{max\_tokens=2048} while running at 1024 (an asymmetry that \emph{favoured} FC;
  re-running changed final pass by $\leq$1 item); Llama's initiation rate required manual
  correction from 97 to 74 after tool-name validation was added; five arms are error-bearing
  and admissible only for the error-rate census, and one previously reported $p$=0.648
  computed on such an arm is withdrawn. All are enumerated in Appendix~A. None is silently
  absorbed into a reported number.
\end{enumerate}

\subsection*{What would change our conclusions}
\label{sec:future}

We name these so the claims are falsifiable rather than merely hedged.

\begin{itemize}
\tightlist
\item
  A \textbf{broken-FC versus repaired-FC RL comparison} on a rollout backend exposing guided
  decoding, everything else fixed. If repaired-FC recovers multi-turn learning, our
  sufficiency claim in \S\ref{sec:sufficiency} is wrong. If it does not, the ``bottleneck is
  not singular'' reading strengthens from one arm to two.
\item
  A \textbf{second independent annotator} on 100--200 stratified outputs. If inter-annotator
  $\kappa$ falls well below 0.9, the magnitude of the scale curve --- though not its
  direction, which the raw-tag counts establish independently --- needs restating.
\item
  The same five-layer measurement on a \textbf{standard tool-use benchmark} (BFCL,
  $\tau$-bench). If emitted intent, server parse, execution and task success coincide there,
  the measurement-validity concern is specific to self-built harnesses and the paper's scope
  narrows accordingly.
\item
  A \textbf{second family's scale ladder}. If the undercount does not grow with checkpoint
  size elsewhere, \S5.2 is a Qwen-plus-hermes fact, not a scaling phenomenon.
\end{itemize}
